# Online Voting System

## Problem Statement
Build a simple online voting solution where valid users can cast their vote securely, only once, and the system can produce accurate results.

## Approach / Logic Used
- Keep a list/database of registered voters and available candidates.
- Authenticate the voter before allowing access to vote.
- Ensure one voter can submit only one vote.
- Store each vote safely and count all votes to generate final results.

## Steps to Execute the Code
1. Open this project folder in Visual Studio Code
2. Open the terminal in the project root
3. Install python extension
4. Run the project using the main command (can use- python app.py or use the run button)
5. Open the output shown in terminal and test the voting flow
